# Implementation Plan: Hybrid Adaptive Control for Quadrotor Motor Failure

This plan outlines the development of a hybrid control system in `gym-pybullet-drones` to compensate for a complete motor failure. The system combines an **Indirect Self-Tuning Regulator (STR)** with a **Reinforcement Learning (RL) Supervisor**.

## Objective
Implement a modular simulation environment where a quadrotor can autonomously adapt to a complete failure of one motor (e.g., Motor 1 stops spinning at $t=5s$) by using RLS for parameter estimation and an RL agent to tune the adaptation dynamics.

- `ctrl/str_controller.py`: Indirect STR implementation using Recursive Least Squares (RLS) to estimate thrust coefficients and update PID/LQR gains.
- `rl/supervisor_agent.py`: RL agent (DQN or PPO) that observes RLS residuals and state error to adjust STR adaptation rates or gain overrides.
- `train_supervisor.py`: Training script for the RL supervisor using `Stable Baselines3`.
- `evaluate_performance.py`: Script to generate comparative plots (Nominal vs. STR vs. Hybrid) and 3D visualizations.
